# Xenium-enhancement-with-different-machine-learning-models
This repository contains the code for the project. It is built up as follows:
- Folder GeneTransformer-Training: This contains the code for the 5 separate tested architectures as .py files
- Folder GeneTransformer-Evaluation: This contains the code for evaluating the 5 respective architectures, again as .py files
- Folder VAE-Training&Evaluation: This contains the code for VAE training and evaluation as separate .py files
- Jupyter notebook Creating data objects: This was used to obtain the .h5ad files from the HEST-1k database, for better data handling
